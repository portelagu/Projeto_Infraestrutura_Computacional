# Projeto em Infraestrutura Computacional 🖥️⚙️

Este repositório contém toda a documentação, planilhas de planejamento e decisões referentes otimização do ambiente de TI da empresa fícticia AgroSmart Tech.

## 🏢 Sobre a Empresa

A **AgroSmart Tech** é uma organização de agronegócio, atuante no setor de **Geoprocessamento e Agricultura de Precisão**, com foco em **entregar soluções ágeis e inovadoras utilizando inteligência artificial e monitoramento aéreo para otimizar as operações no agronegócio**. 

Com o crescimento das operações e a necessidade de garantir maior disponibilidade, segurança e desempenho, este projeto foi iniciado para mapear o cenário atual e projetar uma infraestrutura de TI moderna, escalável e alinhada aos objetivos estratégicos do negócio.
